# 📄 How to Convert HTML Planners to PDFs

You now have **5 ready-to-sell printable planners** as HTML files. Here's how to convert them to PDFs:

---

## 🖥️ Method 1: Use Your Browser (EASIEST - 2 minutes per file)

### On Mac or PC:

1. **Open the HTML file** in any browser (Chrome, Firefox, Safari, Edge)
   - Double-click the HTML file
   - OR right-click → Open with → Chrome/Firefox/Safari

2. **Print to PDF**
   - Press `Ctrl+P` (Windows) or `Cmd+P` (Mac)
   - In the print dialog, choose **"Save as PDF"** or **"Microsoft Print to PDF"**
   - Click **Save**
   - Name it properly: `Budget-Pack-01-Monthly-Budget.pdf`

3. **Repeat for all 5 files**

**That's it!** You now have 5 print-ready PDFs.

## 💡 Pro Tips

### Tip 1: Test Print Before Selling
- Convert one to PDF
- Print it yourself (or at a print shop)
- Make sure everything looks good
- Adjust if needed

### Tip 2: Create Both Letter & A4 Sizes
- These are optimized for US Letter (8.5" x 11")
- For A4 (European size), adjust the `@page` size in CSS:
  ```css
  @page {
      size: A4;  /* Change from 'letter' to 'A4' */
      margin: 0.5in;
  }
  ```

### Tip 3: Offer Editable PDFs
- Most buyers prefer fillable PDFs
- Use Adobe Acrobat (paid) or PDFescape (free online)
- Add form fields to text areas
- Charge $2-3 more for "editable version"

## ❓ Need Help?

**Can't open HTML files?**
- Make sure your browser is set as default for .html files
- Or just drag the file onto your browser window

**PDFs look weird?**
- Make sure you're using "Save as PDF" not "Print"
- Try a different browser (Chrome works best)
- Check the print preview before saving
