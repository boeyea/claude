# 🎨 Complete Printable Planners Creation Guide

## 🎯 Overview

You need to create 69 printable planner pages total across 4 packs. This guide tells you EXACTLY what to create.

**Tools you can use:**
- **Canva** (easiest - free version works) ← RECOMMENDED
- Microsoft Word/Google Docs
- Adobe InDesign (if you know it)
- Hire on Fiverr ($20-50 for all 69 pages)

**Time needed:**
- DIY in Canva: 4-6 hours total
- Hire on Fiverr: 0 hours (just give them this document)

---

## 📐 Universal Specifications

### Page Setup
- **Size**: 8.5" x 11" (US Letter) - create A4 versions later
- **Orientation**: Portrait (unless specified)
- **Margins**: 0.5" on all sides
- **Colors**: Use a consistent color scheme per pack
  - Budget Pack: Greens (#10B981, #059669, #D1FAE5)
  - Productivity Pack: Blues (#6366F1, #4F46E5, #EEF2FF)
  - Wellness Pack: Pinks (#EC4899, #DB2777, #FCE7F3)
  - Student Pack: Oranges (#F59E0B, #D97706, #FEF3C7)

### Design Style
- **Clean & minimal** (not cluttered)
- **Sans-serif fonts** (Inter, Poppins, or Montserrat)
- **Headers**: 24-32pt, bold
- **Body text**: 10-12pt, regular
- **Light backgrounds** with darker text
- **Plenty of white space**

### File Format
- Save as **PDF** (high quality, 300 DPI)
- Make fields **fillable** if possible (Canva Pro can do this)
- Include both **blank** and **lined** versions where applicable

## 🎨 HOW TO CREATE THESE IN CANVA (Step-by-Step)

### Step 1: Set Up Canva
1. Go to canva.com (free version works fine)
2. Click "Create a design"
3. Choose "Custom size" → 8.5 x 11 inches
4. Name your design "Budget Pack - Page 1"

### Step 2: Design Your First Page
1. **Add background**: Choose a light color (e.g., #F9FAFB or #D1FAE5)
2. **Add header**: Click "Text" → Use "Heading" → Type page title
   - Font: Poppins or Montserrat
   - Size: 32pt
   - Color: Your pack's primary color
   - Center it at top
3. **Add content**: Use "Body text" for labels and fields
   - Font size: 12pt
   - Add checkboxes: Use Elements → Search "checkbox"
   - Add lines: Use Elements → Search "line" → Draw horizontal lines
4. **Add margins**: Make sure you have 0.5" space on all sides

### Step 3: Save & Duplicate
1. Click "Share" → "Download"
2. Choose "PDF Print" (high quality)
3. Save as "Budget-Pack-01-Monthly-Budget.pdf"
4. In Canva, click "File" → "Make a copy" for next page

### Step 4: Create All Pages
- Use same color scheme for entire pack
- Keep fonts consistent
- Duplicate layouts when similar (saves time)
- Number your pages clearly

### Step 5: Create A4 Versions
1. Open your design
2. Click "Resize" (Canva Pro feature, OR just remake at A4 size)
3. Change to 210 x 297mm (A4)
4. Everything resizes automatically
5. Save with "-A4" suffix
