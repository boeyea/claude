                         TECHNICAL DETAILS

CSS DESIGN SYSTEM:

Custom Properties (Variables):
- Colors: 20+ semantic color variables
- Gradients: 4 predefined gradient combinations
- Shadows: 6 shadow depths (sm → 2xl)
- Spacing: 6 spacing values (xs → 2xl)
- Radius: 5 border radius values
- Transitions: 3 timing functions

Benefits:
- Consistent theming throughout
- Easy to customize colors
- Maintainable code
- Professional results

KEY CSS TECHNIQUES:

1. Backdrop-filter for glassmorphism
   backdrop-filter: blur(20px) saturate(180%)

2. Gradient text with background-clip
   background: linear-gradient(...)
   -webkit-background-clip: text
   -webkit-text-fill-color: transparent

3. Transform hover effects
   transform: translateY(-2px)
   Creates lift-up button effect

4. Custom scrollbars
   ::-webkit-scrollbar styles
   Thin purple scrollbar

5. CSS Grid layout
   display: grid
   grid-template-columns: 300px 1fr

6. Keyframe animations
   @keyframes fadeIn, slideIn, scaleIn
   Smooth entrance animations

7. Media queries
   @media (max-width: 768px)
   Full responsive breakpoints

JAVASCRIPT ARCHITECTURE:

Class-Based Structure:
- ContentReference class handles everything
- Constructor initializes state
- Async content loading
- Event delegation for performance
- LocalStorage for persistence

Key Methods:
- loadAndParseContent(): Fetches both .txt files
- parseDocument(): Converts text to chapters
- formatContent(): Turns plain text to HTML
- loadChapter(): Displays chapter content
- performSearch(): Full-text search
- toggleBookmark(): Bookmark management
- toggleComplete(): Progress tracking
- saveNotes(): Note persistence

Data Flow:
1. Fetch .txt files from server
2. Parse into chapter objects
3. Store in this.chapters array
4. Render on demand
5. Save state to localStorage
6. Restore on reload

BROWSER COMPATIBILITY:

Tested and works on:
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+
- Mobile browsers (iOS Safari, Chrome Mobile)

Requires:
- ES6+ JavaScript support
- CSS Grid support
- LocalStorage API
- Fetch API
- Backdrop-filter support (for glassmorphism)

Graceful Degradation:
- Falls back if backdrop-filter unavailable
- Still functional without animations
- Works without LocalStorage (just no persistence)
