## AD COPYWRITING (50 prompts)

### Prompt 1: Facebook Ad Campaign Generator
Act as a direct response copywriter with 10+ years of Facebook Ads experience. Create 5 ad variations for [PRODUCT/SERVICE] targeting [AUDIENCE]. For each ad provide: 1) Attention-grabbing headline (40 chars), 2) Primary text (125 words max) using PAS framework (Problem-Agitate-Solution), 3) Call-to-action, 4) Suggested image/video concept, 5) Target audience interests and demographics. Focus on benefits over features. Make it scroll-stopping.

### Prompt 2: Google Search Ad Copy
You're a PPC specialist managing $10M+ in ad spend. Write Google Search Ad copy for [KEYWORD] promoting [PRODUCT/SERVICE]. Create 5 ad variations with: 1) Headline 1 (30 chars max), 2) Headline 2 (30 chars), 3) Headline 3 (30 chars), 4) Description 1 (90 chars), 5) Description 2 (90 chars), 6) Display URL path. Include keywords naturally, highlight unique value proposition, and create urgency. Provide rationale for each variation.

### Prompt 3: Instagram Story Ad Sequence
Act as a social media advertiser specializing in Instagram. Create a 5-slide Instagram Story ad sequence for [PRODUCT/SERVICE]. For each slide: 1) Visual description, 2) Text overlay (concise, under 8 words), 3) Interactive element (poll, question, swipe up), 4) Duration (seconds), 5) Transition effect. Tell a story arc from problem to solution. Make it native to the platform, not salesy.

### Prompt 4: LinkedIn Sponsored Content
You're a B2B marketing expert. Write LinkedIn Sponsored Content for [B2B PRODUCT/SERVICE] targeting [JOB TITLE/INDUSTRY]. Create: 1) Post copy (150 words) that provides value first, 2) Compelling headline, 3) Clear CTA, 4) Comment starter question, 5) A/B test variation, 6) Targeting recommendations (job titles, industries, seniority). Make it professional but engaging, not corporate jargon.

### Prompt 5: Retargeting Ad Copy
Act as a conversion rate expert. Create retargeting ad copy for people who [VISITED PAGE/ABANDONED CART/DOWNLOADED LEAD MAGNET]. Write 3 ad variations addressing: 1) Why they didn't convert (objection handling), 2) Social proof or urgency angle, 3) Special incentive offer. Include headlines, body copy, and CTAs. Make them feel like the ad "gets" them.

### Prompt 6: YouTube Pre-Roll Ad Script
You're a video ad specialist. Write a 30-second YouTube pre-roll ad script for [PRODUCT/SERVICE]. Structure: 1) Hook (first 3 seconds to stop skip), 2) Problem identification (5 seconds), 3) Solution presentation (12 seconds), 4) Social proof or credibility marker (5 seconds), 5) Clear CTA (5 seconds). Include visual directions. Make every second count. Write conversationally.

### Prompt 7: Native Advertising Copy
Act as a native ad expert. Create native advertising content for [PRODUCT/SERVICE] that will run on [PLATFORM/PUBLISHER]. Write: 1) Headline that matches editorial tone (60 chars), 2) Article-style landing page intro (200 words), 3) 3-5 subheadings with sections, 4) Natural product integration points, 5) Soft CTA. Make it valuable content first, ad second. Disclose sponsorship appropriately.

### Prompt 8: TikTok Ad Concept
You're a Gen Z marketing expert who understands TikTok culture. Create 3 TikTok ad concepts for [PRODUCT/SERVICE]. For each: 1) Hook in first 1 second, 2) Video flow and beats, 3) Text overlays, 4) Sound/music suggestion, 5) Hashtag strategy, 6) CTA placement. Make it feel native to TikTok, use trending formats, be entertaining first. No corporate ads.

## HOW TO USE MARKETING PROMPTS

### Quick Start Guide:

**For Ad Copy**: Copy the relevant ad prompt → Replace bracketed variables → Get 5+ variations → A/B test the top 3

**For Email**: Use sequence prompts for campaigns → Customize for your brand voice → Test subject lines → Track open and click rates

**For Landing Pages**: Start with structure prompt → Fill in your details → Add social proof → Get feedback → Iterate based on conversion data

**For Social**: Use content calendar prompts monthly → Batch create content → Schedule ahead → Engage with responses

### Pro Marketing Tips:

1. **Keep a swipe file**: Save your best ChatGPT outputs in a Google Doc organized by type
2. **Iterate, don't accept first output**: Ask ChatGPT to rewrite focusing on different angles
3. **A/B test everything**: Use these prompts to generate multiple variations for testing
4. **Brand voice consistency**: Start sessions by describing your brand voice to ChatGPT
5. **Combine prompts**: Use ad copy + landing page + email sequence for full campaign
